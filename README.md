# DELBAN — Website demonstrativo

Website responsivo em HTML, CSS e JavaScript puro, preparado para publicação no GitHub Pages.

## Publicar
1. Coloque o ficheiro oficial `logo.png` na raiz deste repositório.
2. Abra **Settings → Pages** no GitHub.
3. Em **Build and deployment**, selecione **Deploy from a branch**, branch `main`, pasta `/ (root)), e guarde.
4. O site ficará disponível em `https://felicidadedias.github.io/Consultorio-Delban/` depois de o GitHub Pages concluir a publicação.

## Funcionalidades
- Layout adaptável a telemóvel, tablet e computador.
- Menu móvel, secções de serviços, exames, oferta anunciada, horário, contactos e perguntas frequentes.
- Ligações para telefone, Google Maps e WhatsApp.
- Formulário que prepara uma mensagem no WhatsApp; não recolhe nem guarda dados num servidor.
- Imagens ilustrativas externas do Unsplash, a substituir por imagens autorizadas do estabelecimento.

## Antes de publicar como site oficial
- Adicionar o ficheiro oficial `logo.png`.
- Confirmar por escrito nome comercial, morada, horários, contactos, preços e condições da promoção.
- Confirmar os serviços efetivamente prestados e os profissionais/credenciais que podem ser apresentados.
- Substituir imagens de banco de imagens por fotografias autorizadas, caso o cliente prefira.
- Rever os textos clínicos e legais com o responsável do estabelecimento.
- Confirmar se o número de WhatsApp usado para pedidos é o correto. Por defeito, o formulário abre o número `+244 946 848 400`.

## Transparência
O conteúdo foi preparado a partir do cartaz fornecido pelo solicitante e do link de localização. As ofertas e serviços são apresentados como informações anunciadas, não como validação independente de eficácia clínica, licenciamento ou disponibilidade. A morada completa e alguns horários precisam de confirmação. As fotografias são ilustrativas e não representam necessariamente o estabelecimento nem os seus profissionais.

## Créditos de imagens
As fotografias de demonstração são carregadas de `images.unsplash.com`. Verifique os termos e a adequação das imagens antes da utilização comercial final; substitua-as por fotografias próprias com consentimento quando possível.
